# Навигационный анализатор треков

Лабораторная работа № 3 по дисциплине «Алгоритмические языки и технологии программирования». Программа на C читает бинарный файл с навигационными точками, переносит записи в односвязный список, строит бинарное дерево поиска высот и сохраняет статистику маршрута.

## Сборка и запуск

Из каталога `lab3_final`:

```sh
make
make run
./build/flight_analyzer data/flight_data6.bin
make clean
```

Если путь к файлу не задан, используется `data/flight_data6.bin`. При запуске с аргументом можно выбрать любой совместимый бинарный файл:

```sh
./build/flight_analyzer путь/к/файлу.bin
```

Результат работы записывается в `output/statistics.txt`.

## Формат бинарного файла

Каждая запись занимает 16 байт и записана в следующем порядке:

```c
typedef struct {
    uint32_t timestamp_ms; /* 4 байта */
    float lat_rad;         /* 4 байта */
    float lon_rad;         /* 4 байта */
    float alt_m;           /* 4 байта */
} BinaryRecord;
```

Широта и долгота хранятся в радианах и при чтении переводятся в градусы.
